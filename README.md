# GolShop Fútbol Store

Diseña el prototipo de una app móvil (mobile-first, 390px de ancho) llamada
"GolShop": un marketplace de camisetas de fútbol y accesorios.

Estilo: moderno y deportivo, fondo oscuro, verde césped como color principal
y detalles dorados. Tarjetas con esquinas redondeadas, tipografía clara.
Navegación inferior con 4 pestañas: Inicio, Carrito, Chat y Perfil.

Pantallas:
1. Login y Registro (correo, contraseña, botón principal).
2. Inicio: barra de búsqueda, chips de filtro (equipo, talla) y una cuadrícula
   de tarjetas de productos (imagen, nombre, precio).
3. Detalle de producto: imagen grande, equipo, selector de talla, precio y
   botón "Agregar al carrito".
4. Carrito: lista de productos con cantidad, total y botón "Comprar".
5. Mis pedidos: historial con estado del pedido.
6. Chat con el vendedor: burbujas de mensajes y campo de texto.
7. Perfil: foto (con botón de cámara), nombre, dirección (con botón de
   ubicación) y cerrar sesión.
8. Panel Admin: lista de productos con botones crear, editar y eliminar.

Usa datos de ejemplo (camisetas de equipos populares, precios en pesos
colombianos). No conectes backend, solo el diseño y la navegación.
